# FinAI — модуль инициатив

Кликабельный прототип интерфейса для пользовательского тестирования. Реализован на React, Vite и компонентах SDDS FinAI.

## Локальный запуск

```sh
pnpm install
pnpm dev
```

Откройте `http://127.0.0.1:4173/`.

## Сборка

```sh
pnpm build
```

GitHub Actions собирает проект и публикует папку `dist/` на GitHub Pages при каждом push в `main`.
